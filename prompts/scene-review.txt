1. **[page_repetition]** Repetition — name any two pages whose images would look near-identical: same location, same grouping, same camera distance, same action. Say which one should change and how.
2. **[visual_arc]** Visual arc — read as a flipbook, does framing build with the plot? Name the page where intensity sags or spikes out of order.
3. **[continuity]** Continuity — does anything contradict an earlier page: a character's clothing, an object that was left behind, a time of day that moves backwards, a location that changes shape?
3b. **[clothing_incomplete]** Clothing completeness — every character in a brief must be described wearing a top, a bottom and footwear; a character whose outfit replaces the legs needs the tail or fin instead of bottom and footwear, and must have no feet or shoes. Name any page whose prose dresses a character in headwear alone, or in fewer than those three, or that names a clothing category key (`standard`, `costumed`) instead of the garments. A character whose body has no feet in the scene (a tail, fins) is exempt from footwear there.
4. **[interaction_multiple_actions]** Single moment — name any brief that describes more than one moment in time, a montage, or an action with no visible subject. Characters on one page share one focal point visible in the frame; a page where each figure performs its own separate activity is a fault even when the actions share a cause. Characters with the same goal do the same thing in the same place — a searching group stands together scanning, never split across separate spots with roles. Rewrite around the single focal event, gathering same-goal characters into one group.
5. **[cast_over_cap]** Cast — name any scene with more than {MAX_CHARACTERS_PER_SCENE} named characters, or a character present in the page's plan line (PAGE PLAN above) but absent from the brief. A brief with no named characters is correct when its plan line stages the subject alone; fault it only when the plan line names a character or the page carries nothing. If PAGE PLAN reads (no plan data), skip the comparison.
5b. **[cast_over_three]** Figure count — name any page whose frame holds more than three figures, named or anonymous, at foreground or midground depth. A page that is a portrait, an arrival, or a crowd the action needs is exempt; otherwise rewrite to three by pushing the extras to background depth with the separation the plan line supports, or by moving the shot wider so the group reads as one mass. Never drop a character the plan line lists.
6. **[character_fields]** Character fields — every character needs depth and a drawable expression naming brows, eyes or mouth. Name any that is missing one, or that uses a bare mood word.
6b. **[scene_intent]** Scene intent — every page needs a `sceneIntent`. Name any that is missing, that covers more than one moment, or that names a character absent from `characters[]`.
6c. **[depth_unearned]** Depth must be earned — every character in `characters[]` must be described in the prose, and one marked `background` must be placed there in words: further off, small in the distance, across the space, behind the others. Name any page listing a character the prose never describes, or marking a character `background` while the prose gathers the whole cast in one spot. A `background` figure also needs the plan line to require the separation (left behind, watching from afar, arriving in the distance) — otherwise bring them to the group's depth. Characters standing on one small shared surface — a boat, a raft, a cart, a wagon, a sled — are all at the same depth: name any page marking one of them `background` and change that depth to match the others. Rewrite the prose to place that character at its declared depth, or change the depth to match the prose.
7. **[drawability]** Drawability — name any instruction an illustrator could not execute: a character facing one way while looking at someone behind them, an impossible viewpoint, a described detail too small to read at page size, or a character declared `back view` whose action target the brief places closer to the camera than they are — moving toward a foreground character requires facing the camera. Also name any character interacting with an invented feature of a real landmark (a gap, opening, or ledge the landmark does not have) — rewrite to a feature the landmark actually has.
7b. **[closeup_below_waist]** Close-up framing — a `close-up` frame ends at the waist. Name any page with `shot: close-up` whose prose, poses, or interactions stage below-waist action — kneeling, crouching, sitting, stepping, or feet-on-ground contact. A garment list naming footwear does not count. Rewrite that page's `shot` to `medium` and change nothing else.
7c. **[themed_setting_bare]** Themed-world setting — a page set in a fantastical world, or a real place the story's premise has transformed into one, dresses its environment with a lot of that world's characteristic elements. Name any such page whose setting is bare and rewrite it, adding elements to the environment and background only — never characters, never the action.
7d. **[footing]** Footing — name any standing character whose declared position lands where the scene offers nothing to stand on (open water, air, a drop) while their `position` field is a bare grid term. A figure on ground, in the water as a swimmer, or whose position already names its surface is fine. Partially immersed figures (wading, ankle-deep, knee-deep) are a fault — restage at the water's edge or as swimming. Rewrite the faulted position to name the standable surface (bank, path, deck, walkway).
8. **[gaze_budget]** Gaze — a page names at most one gaze target, and the composition makes that target the frame's dominant element: large, central, or nearest the camera. Name any page naming a second gaze target, aiming a gaze at something small or distant, or sending a gaze to the viewer outside a portrait page. Rewrite so every figure looks at the one target or at the page's action, and enlarge or centre that target.
8b. **[contact_not_pose]** Contact — a demanded grip or touch must be written as a visible pose: what the fingers wrap, where the weight leans, what the body presses against. Name any page whose prose says only "hand on X", "grips X", "touches X". Name also any figure given two grips at once. Rewrite the prose into the visible pose and leave one hand-duty per figure.
8c. **[force_at_rest]** Force — `taut`, `strained`, `braced`, `straining` render at rest. Name any page relying on those words and rewrite them as the shape the force makes ("the rope is a straight line from the post to her hands", "the sail curves out toward the bow").
8d. **[elevation_unsupported]** Elevation — a figure off the ground needs its support written into the pose (which rung the feet are on, which edge the hands hold, what the heels press against). Name any elevated figure without one and rewrite the pose to name the support.
9. **[negation_named]** Negation — naming a thing that must be absent paints it. Name any page containing "no …", "without …", "bare …", "does not …", "empty of …" in its prose or any metadata field, and rewrite it to describe what does occupy that space.
9b. **[prop_unheld]** Props — a plot-critical object is in a named character's hands, or it is the page's subject filling the foreground. Name any page where the plan line's key object is neither, and any page with more than two named props standing unheld. Rewrite by putting the object into a character's hands or by making it the subject.
9c. **[scale_unanchored]** Scale — `small in the distance`, `far off`, `tiny` render at foreground size. Name any page using them without a comparison to something visible in the same frame, and rewrite with the comparison ("the far ship spans less than the main character's hand").
10. **[closeup_environment]** Close-up hygiene — a `close-up` brief describes only what that frame holds. Name any `close-up` page carrying a paragraph of surrounding environment and rewrite it, moving the setting into `emptyScenePrompt` or changing `shot` to `medium`.
10b. **[era_landmark_named]** Real place, other era — naming a real location pulls in how it looks today. Name any page whose `era` or genre differs from the place as it stands while the prose names the place, and rewrite to describe its shape, materials and surroundings instead; leave its LOC id in `objects[]`.
10c. **[critique_in_brief]** Critique leakage — a brief must describe characters only from CHARACTER DETAILS. Name any page whose prose or metadata carries review commentary, or gives a character an age, build or outfit that CHARACTER DETAILS does not, and rewrite it back to the character's real description.
