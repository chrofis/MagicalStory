# CLOTHING REQUIREMENTS

Determine which clothing variants each character needs, based on the page plan.

- Mark `used: true` only for variants that actually appear.
- Set `costumed.used: true` whenever the theme, setting or era implies special clothing, and name it in `costumed.costume` (`medieval`, `wizard`, `pirate`, `firefighter`, `1920s`, …). Leave it false only for a present-day story in everyday clothes.
- If any character is costumed, every cover uses the costumed variant for every cover character.
- `description` is the FULL final outfit for this story — top, bottom, footwear, accessories — as one self-contained sentence. Start from the character's stored clothing above; keep it, add a story-relevant accessory, or change a garment the story requires. The avatar generator uses it verbatim.
- Costumed descriptions name every slot the character actually wears: headwear, top, bottom, footwear, belt/waist, outer layer. Each slot names colour and material. OMIT a slot they do not wear; never write it out as `none`. Clothing only — no pets, carried objects or bag contents.
- Name structural garment parts, not just the garment. Dungarees, pinafore, suspenders, kilt, kimono, sari and similar render as plain garments when only named: keep the garment name in front and spell out its parts ("denim dungaree shorts — square bib panel over the chest held by two shoulder straps").
- No headwear, helmets, crowns or masks that cover the face.
- **The costume must read as that costume at a glance.** Every garment is one that costume is known for, named with the word that names it there. A garment that only hints at the theme does not count, and neither does one borrowed from a different costume.
- **Every garment matches the character's sex.** A male character wears garments made for boys or men, a female character garments made for girls or women. When a costume has a male and a female form, each character wears the form matching theirs.
- **A child's swimwear or costume top is a modest full-coverage garment** (`swim shirt`, `swim top`, a one-piece) — never `bikini`, a bare chest, or a bare midriff.
- **Characters are told apart by colour.** A different dominant colour per character, on their largest garment.
  - Plain colour words only: red, blue, green, yellow, orange, purple, brown, black, white, grey.
  - Never distinguish by a print, badge, pin, brooch, embroidery, trim, buckle, laces, feather, earring, watch or buttons, or anything small.
- **Outfits differ in garment type and silhouette, not colour alone.** Two characters never wear the same set of garments recoloured. The story world decides the wardrobe; within it one wears a long coat, another a vest, another rolled sleeves and a sash. Vary headwear and footwear the same way.
- **One state per garment slot.** Never two that exclude each other. Omit a slot the character does not wear.
{STYLE_WARDROBE}
- Never write `none`, `n/a`, `tbd` or `""` as a value. Omit the field instead. `used: false` carries no `description`.
