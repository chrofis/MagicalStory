# YOUR TASK

Find the pages that are weak and rewrite only those. If no early page states plainly what must happen and why, rewrite the earliest fitting page so a character says it. Rewrite any page that carries an abbreviation or acronym: name the thing the way a child says it. A page that already works stays as it is. The story must still deliver the brief above.

Return only the pages you rewrote. Omit every page you left alone. If no page needs rewriting, return the marker followed by NONE and nothing else.

Do not rewrite a page for small stylistic preference. Rewrite it when it has a real problem from the list below.

Never use an em-dash (—) or an en-dash (–), anywhere, for any purpose. Replace every one you find with a comma, a full stop, a colon, or parentheses, and recast the sentence if none of those fit.

Rewrite any page with a sentence broken off for effect, a bare fragment standing as a sentence, or caption-style lines describing the scene like stage directions: recast them as someone telling the story aloud, in complete sentences.

Unless the reading level asks for very short sentences, rewrite any page where several short sentences run in a row or consecutive sentences open with the same subject and verb: merge some so a short sentence sits among longer ones. Rhetorical set-pieces are rationed to one use in the whole book — a paired negation (kein X, kein Y), a coined saying or incantation, a one-sentence paragraph for drama; rewrite every occurrence past the first as plain narration.

Rewrite any page carrying a sentence longer than the reading level allows, a subordinate clause inside another subordinate clause, or a word a child at that level does not already use.

Judge the text as a reader who has only the pages in front of them. They never see the brief, the character details or the scene outlines — those are given to you so you know what the book is FOR, never as evidence that something works. A motivation, trait or fear that exists only in the character details and never reaches the page is a failure to fix, not a justification. Never resolve a weakness by citing the brief.

Work in two steps.

Step 1 — write the analysis. Answer every check below in full, naming pages and quoting lines. This is the work: a page is weak because a check found something specific wrong with it, not because it could be phrased differently.

Step 2 — rewrite the pages your analysis found problems on. A page no check flagged stays exactly as it is. End the analysis with a line per named problem — the problem, then the page(s) the rewrite fixes it on, or the reason it stands. A named problem with neither is a failed review. Every AUDIT FINDING above enters that ledger the same way, and it has three ways to close: fixed on a page, the detail removed, or a stated reason it stands. A fault whose reason exists in the scene outlines is fixed by saying that reason on a page, never by citing the outline. Close a fault about a missing path, arrival or move by showing it happening on one of the pages, or by leaving it to the page turn; never by opening a page with the move already completed. A fault about something the book never established is closed by establishing it on an earlier page or by cutting the claim, never by adding a sentence that asserts both the claim and its opposite. A fault naming an ability or event the pages need but never establish is closed by establishing it earlier, never by describing the moment more vividly.

Take the second way whenever the detail that caused the fault carries no plot: drop the detail instead of inventing an event to justify it. Never invent an event that makes an established obstacle easier to pass, and never state a clock time or a named part of the day to close a fault — light, shadow and what the characters do carry time instead.

A sentence naming what a character feels, notices, or almost does is never the sentence you cut to make room. Where a fix needs room, shorten a sentence that names only objects and positions. End the ledger with one line per rewritten page listing any sentence you removed from it.
