# Scene Hint Format

Each scene hint is a JSON block for direct image generation (no further expansion).
It must be detailed enough to illustrate without additional context.
Every field of a scene hint is written in English, whatever the story language: a word of the story language for a thing, a dish or a creature becomes its English noun in the hint (the page text keeps the story's own word). A real place's name stays as the LANDMARKS list gives it.

```json
{
  "scene": {
    "imageSummary": "[2-3 sentences: the visual moment with character positions, mood, colors, lighting, atmosphere]",
    "setting": {
      "location": "[Location Name [LOC001]]" or "none",
      "indoorOutdoor": "[indoor/outdoor]",
      "description": "[visual setting details: colors, textures, atmosphere]",
      "lighting": "[light quality and the direction it comes from]",
      "camera": "[close-up|medium|wide|ultra-wide]",
      "depthLayers": "[describe what's in foreground, midground, background]"
    },
    "timeOfDay": "[{TIME_OF_DAY_ENUM}]",
    "weather": "[{WEATHER_ENUM}]",
    "characters": [
      {
        "id": "[CHR001 or null for main character]",
        "name": "[Name]",
        "position": "[left/right/center]",
        "action": "[what they're doing]",
        "expression": "[facial expression — one instant, never a transition such as changing from one expression to another]",
        "clothing": "{CLOTHING_ENUM}",
        "depth": "[foreground|midground|background]",
        "perspective": "[front|side|back view|over-the-shoulder]"
      }
    ],
    "objects": [
      {"id": "[ART001]", "name": "[Object name]", "position": "[where in scene]", "size": "[OMIT unless this object's size matters on this page; then how big it is here against the character beside it or the surface it rests on. No metric or imperial units.]"}
    ],
    "interactions": [
      {"character": "[Name]", "object": "[object name or ART001]", "where": "[short sentence naming the object as the contact action, e.g. 'holds the lantern in both hands']", "priority": "[essential|normal|low]"}
    ],
    "background": "[empty|a few passersby|busy crowd|dense forest|etc.]",
    "population": "[{POPULATION_ENUM}]"
  }
}
```

- MAX 3 characters per scene — the main character plus at most two others — and keep the cast minimal: add a secondary character only when the story needs one. Use character names, not descriptions.
- `characters.id`: use visual bible `CHR` IDs for secondary characters (e.g., `"CHR001"`). Use `null` for the main character (who has reference photos).
- Every person named in `imageSummary` also appears in that scene's `characters`: with their visual bible `CHR` id, or — when the visual bible has no entry for them — with a `description` field giving age, build, hair, face and clothing.
{CLOTHING_RULE}
- `characters.depth` (optional, default `foreground`): how far from camera. Use `background` for tiny/distant figures. `depth` never states a size: a stated size holds at every depth.
- `characters.perspective` (optional, default `front`): camera angle on this character.
- `setting.location`: use `"Name [LOC001]"`.
- `setting.camera`: shot type determines facial detail visibility. `close-up`/`medium` = expressions visible. `wide`/`ultra-wide` = body language only.
- `objects`: include visual bible items visible in the scene with their IDs. `size` restates the object's scale for this page's shot, in the same shape the visual bible uses; it overrides the bible entry where they differ.
- `background`: describes crowd/environment density. Tells image generator if scene feels isolated or populated. The people it names are the page's `population`: a `background` with passers-by or a crowd is never a `cast_only` page.
{POPULATION_FIELD}
- `interactions`: 1-4 visible character-to-object or character-to-character contacts, one row per foreground/midground character. `priority: "essential"` for the page's central action, `"low"` for incidental gaze or pose. {CONTACT_VERB} When several characters use ONE object together, join their names with ` + ` in one row — separate rows with the same object render as duplicate objects. {SHARED_GRIP} {SMALL_PROP_CONTACT} Omit pure ground/floor contact, leaning on walls and sitting on generic chairs. Every row also appears in the story text as the same physical contact. **Coverage:** every foreground/midground character appears in `interactions` exactly once, and `interactions` is never empty on a page that has one. A character with no real action gets a `priority: "low"` row naming what they watch or stand beside (e.g. `{"character": "[Name]", "object": "[what they watch]", "where": "watches the [object]", "priority": "low"}`): without it the image model draws a camera-facing portrait. Background characters are exempt.
- `timeOfDay` and `weather` (required on every scene): {SCENE_LIGHT_FIELD}

# THE PLAN

{ARC_PLAN}

The Visual Bible, the title and the cover scene above are binding. Use exactly their ids, cast, objects, locations and backgrounds: every secondary character, animal, artifact and location in your scene hints cites an id from the Visual Bible, and you add no recurring character, animal, object, location or background (a figure the story needs on one page only follows the one-page rule above: no entry). Ids are checked: a `characters` row's id is null (the main character) or a CHR or ANI id the Visual Bible lists, an `objects` row's id is an ART id the Visual Bible lists, and the location is a LOC id the Visual Bible lists. Never write an id the Visual Bible does not list, and never put an animal or object into `characters` under an invented id; a Visual Bible figure or object that a page does not need stays out of that page's hint, and every one is used on some page. A name appears only if the Visual Bible or the Characters list gives it; you invent no name for a figure, toy, animal or place. An element's listed pages say where the planner expected it: use it on another page when your repaired story needs it there. Each scene's setting is a background of the Visual Bible.

The Visual Bible is the story's world and it is already drawn: set the story in its locations and with its objects. Each page's `setting.location` is one of the Visual Bible's locations ("none" only when the Visual Bible lists no location), a bible object appears in the hints of the pages it fits under its bible name and id, and you never move the story to another place or swap a bible object for another. Repair the arc inside this world.

The ARC is a fast draft and only advisory: keep its idea (the situation, the cast, the central object, the ending the Story Idea asks for) and tell it as a sound story. Repair it while you write:
- The commissioned topic and the Story Idea drive the problem: the conflict is the one they name, and the way out uses what the idea and the characters' details give (their toy, pet, activity).
- Everything the story introduces (a skill, a clue, a creature's trick, an object, a map, a promise) pays off before the end, or you drop it. Nothing is set up and left.
- Counts, states and places stay consistent from page to page: a thing set down stays there until someone picks it up, a thing in hand is not lost without a scene that loses it, a counted collection counts up and arrives at the stated number.
- Every beat follows from the one before for a reason the reader can see; the low point has its own scene and the ending answers the opening.
- Every figure and object of the Visual Bible is used in the story, with a role, where it matters.
- The planner wrote English planning notes: take no wording, number word or name of a thing from them for the prose; the prose is yours, in the story language and the reading level. The title is fixed; write no title.
